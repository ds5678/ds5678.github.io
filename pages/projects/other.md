# Other Projects

## Octokit.Webhooks

I implemented [AOT support](https://github.com/octokit/webhooks.net/pull/920) for [Octokit.Webhooks](https://github.com/octokit/webhooks.net).

## ILSpy

I made many [pull requests](https://github.com/icsharpcode/ILSpy/pulls?q=is%3Apr+author%3Ads5678+is%3Aclosed) improving the output of [ILSpy](https://github.com/icsharpcode/ILSpy), which is used in the Visual Studio debugger when stepping into assemblies without source code available.

## MelonLoader

I made many [pull requests](https://github.com/LavaGang/MelonLoader/pulls?q=is%3Apr+author%3Ads5678+is%3Aclosed) to [MelonLoader](https://github.com/LavaGang/MelonLoader), a Unity mod loader.

## Il2Cpp Versions

I maintain a [repository](https://github.com/nneonneo/Il2CppVersions) archiving changes in the [Il2Cpp](https://docs.unity3d.com/6000.5/Documentation/Manual/scripting-backends-il2cpp.html) headers.

## Type Trees

Type trees are a specification for the binary format of Unity assets. I maintain a few repositories related to the acquisition and storage of them.

* [TypeTreeDumper](https://github.com/DaZombieKiller/TypeTreeDumper/pulls?q=is%3Apr+author%3Ads5678+is%3Aclosed)
* [TypeTreeDumps](https://github.com/AssetRipper/TypeTreeDumps)
* [Tpk](https://github.com/AssetRipper/Tpk)

## LLVM

I contributed pull requests to the .NET bindings libraries for [clang](https://github.com/dotnet/ClangSharp/pulls?q=is%3Apr+author%3Ads5678+is%3Aclosed) and [LLVM](https://github.com/dotnet/LLVMSharp/pulls?q=is%3Apr+author%3Ads5678+is%3Aclosed).
