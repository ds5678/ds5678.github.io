# C++ Translation

## AssetRipper.Translation.LlvmIR

This [tool](https://github.com/AssetRipper/AssetRipper.Translation.LlvmIR) translates LLVM IR to .NET CIL, enabling conversion of C++ code to C#.

### AssetRipper.Conversions.FastPng

This [C# port](https://github.com/AssetRipper/AssetRipper.Conversions.FastPng) of [fpng](https://github.com/richgel999/fpng) writes PNG files quickly and efficiently.
