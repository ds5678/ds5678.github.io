## AssetRipper.CIL

I find myself frequently writing CIL bytecode, so I made a [library](https://github.com/AssetRipper/AssetRipper.CIL) to help with that. It's built on top of [AsmResolver](https://github.com/Washi1337/AsmResolver), a magnificient set of libraries, which I [occasionally contribute to](https://github.com/Washi1337/AsmResolver/pulls?q=is%3Apr+author%3Ads5678+is%3Aclosed).

## Il2CppInterop

[Il2CppInterop](../projects/il2cpp-interop.md) generates output as .NET CIL. Ensuring efficiency and correctness requires a solid understanding of the .NET CIL architecture and the semantics of each byte code instruction.
